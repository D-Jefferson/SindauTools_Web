FORMATADOR MATRICULA

Como usar

Formatar

Insira os dados extraidos do banco de dados na caixa de texto esquerda

Clique em formatar e copie utilizando o botao de copiar na caixa de texto direita.

OBS: Certifique se copiou os dados corretamento.

Exportação CSV

Gere um arquivo CSV com o botão "Exportar CSV" e coloque no Postman.

Esta opção é utilizada em instabilidade que demanda muitas requisições.

OBS: Só funciona com o Postman para envio de requisições automatica via API.
